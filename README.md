# Eagler Server
## 日本語 / Japanese
1. このレポジトリをフォークしてください
2. その後コードスペースを作成してください
3. ターミナルを開きます
4. cd velocityと入力します
5. sudo chmod +x ./velocity.shと入力します
6. ./velocity.shと入力します
7. 新しいターミナルを開きます
8. cd Serverと入力します
9. sudo chmod +x ./server.shと入力します
10. ./server.shと入力します
11. ポートのところを開きます
12. 25577と書いてるところのURL(?)をコピーします
13. httpsの部分をwssに変えてEaglerのサーバーアドレスのところに貼りつけます
14. 最後サーバーに接続できるとサーバーの完成です
